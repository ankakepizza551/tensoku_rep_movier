# 非想天則 リプレイ録画ツール

東方非想天則 (.rep) を自動で録画して .mp4 に変換するツールです。

## 必要なもの

- Windows 10 / 11
- Python 3.11 以上
- 東方非想天則 (th123.EXE)
- **ffmpeg.exe** → `ffmpeg/` フォルダに置く (下記参照)

## FFmpeg のセットアップ

1. https://github.com/BtbN/FFmpeg-Builds/releases から  
   `ffmpeg-master-latest-win64-gpl.zip` をダウンロード
2. 解凍して `bin/ffmpeg.exe` を取り出す
3. このツールの `ffmpeg/` フォルダに置く

```
tensoku_rep_movier/
└── ffmpeg/
    └── ffmpeg.exe  ← ここに置く
```

## インストール

```
pip install -r requirements.txt
```

## 使い方

```
python main.py
```

1. **th123.EXE** のパスを設定
2. **.rep ファイル** を選択
3. **出力フォルダ** を選択
4. **録画開始** を押す
5. ゲームが自動で起動・再生されます
6. リプレイが終わったら **録画停止** を押すか、ゲームを閉じる

## 詳細設定

| 項目 | 説明 | デフォルト |
|------|------|-----------|
| 起動待ち(秒) | ゲーム起動後キー操作するまでの待機時間 | 5 |
| キー間隔(秒) | 各キー操作の間隔 | 0.3 |
| ↓ 回数 | タイトルからリプレイメニューへの↓キー回数 | 6 |
| Z 回数 | リプレイ選択・開始のZキー回数 | 4 |

## 注意

- ゲームのリプレイフォルダ内に `!` フォルダを作り、その中に一時ファイルを作成します  
  (ゲーム内のリストで一番上に表示させるためです。録画終了後に自動削除されます)
- 録画中はゲームウィンドウを最前面に保ってください
- 音声を録音したい場合は、UIの「音声録音」からデバイスを選択してください（PCのステレオミキサー等の有効化が必要です）
- リプレイの自動停止時間はファイルサイズからの推測のため、試合終了前に録画が切れてしまう場合は手動で「録画停止」を押してください
- バッチ録画（複数ファイルの連続処理）中にブラウザなど他のウィンドウを操作すると、キー操作がゲームに送信されず失敗する場合があります。録画中はPCの操作を控えてください
- SWRSToys などのModを使用している場合、メニュー構造が変わる場合があります

## exe 化 (配布用)

```
pip install pyinstaller
pyinstaller --onefile --windowed --name 非想天則リプレイ録画 main.py
```

`ffmpeg/` フォルダは dist フォルダに手動でコピーしてください。
