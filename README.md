# 非想天則 リプレイ録画ツール

東方非想天則 (.rep) を自動で録画して .mp4 に変換するツールです。

## 必要なもの

- Windows 10 / 11
- Python 3.11 以上
- 東方非想天則 (th123.EXE)
- **ffmpeg.exe** → `ffmpeg/` フォルダに置く (下記参照)
- [VB-Cable](https://vb-audio.com/Cable/) (「ゲーム音のみ録音」を使う場合のみ)

## FFmpeg のセットアップ

1. https://github.com/BtbN/FFmpeg-Builds/releases から  
   `ffmpeg-master-latest-win64-gpl.zip` をダウンロード
2. 解凍して `bin/ffmpeg.exe` を取り出す
3. このツールの `ffmpeg/` フォルダに置く

```
tensoku_rep_movier/
└── ffmpeg/
    └── ffmpeg.exe  ← ここに置く
```

## インストール

```
pip install -r requirements.txt
```

## 使い方

```
python main.py
```

1. **th123.EXE** のパスを設定
2. **.rep ファイル** を選択
3. **出力フォルダ** を選択
4. **録画開始** を押す
5. ゲームが自動で起動・再生されます
6. リプレイが終わったら **録画停止** を押すか、ゲームを閉じる

## 詳細設定

| 項目 | 説明 | デフォルト |
|------|------|-----------|
| 起動待ち(秒) | ゲーム起動後キー操作するまでの待機時間。通常はタイトル画面への到達を自動で検出するので、検出できない環境でだけ使われます | 5 |
| キー間隔(秒) | 各キー操作の間隔 | 0.3 |
| ↓ 回数 | タイトルからリプレイメニューへの↓キー回数 | 6 |
| Z 回数 | リプレイ選択・開始のZキー回数 | 4 |

## 注意

- ゲームのリプレイフォルダ内に `!` フォルダを作り、その中に一時ファイルを作成します  
  (ゲーム内のリストで一番上に表示させるためです。録画終了後に自動削除されます)
- 録画はゲームウィンドウ単位でキャプチャしているため、他のウィンドウが重なっても正しく録画されます。**最小化だけはしないでください**（最小化中は描画されないため真っ黒になります）
- 各リプレイの開始時（タイトル→リプレイ再生までのメニュー操作、数秒間）はゲームウィンドウを一時的に最前面に呼び出します。この間だけキー入力が横取りされるので、キーボード操作は避けてください。再生が始まれば他の作業をして問題ありません
- 音声を録音したい場合は、UIの「音声録音」からデバイスを選択してください（PCのステレオミキサー等の有効化が必要です）
- リプレイの終了はゲームの画面状態から検出して自動で録画を止めます (Ver1.10a 対応)。検出できない環境ではファイルサイズから推測した時間で止めるため、試合終了前に録画が切れてしまう場合は自動停止を OFF にして手動で「録画停止」を押してください
- 音声は「音声録音」で選んだデバイスに流れている音をすべて録ります。ゲーム音は既定の再生デバイスから出るので、既定デバイスのループバックを選んでください
- th123.EXE を「管理者として実行」する設定にしている場合は、このツールも管理者として実行してください (通常は不要です)
- 設定は、exe 版では `%APPDATA%\SokuReplayRecorder\config.json` に、`python main.py` で動かす場合はこのフォルダの `config.json` に保存されます
- SWRSToys などのModを使用している場合、メニュー構造が変わる場合があります

## exe 化 (配布用)

```
py build.py
```

`dist/非想天則リプレイ録画/` に exe 一式が出力されます (PyInstaller は未導入なら自動でインストールされます)。  
`ffmpeg/ffmpeg.exe` と `README.txt` も自動でコピーされるので、配布時はこのフォルダをまるごと zip にしてください。
