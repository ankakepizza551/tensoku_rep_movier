========================================
  非想天則 リプレイ録画ツール
========================================

東方非想天則 (.rep) のリプレイファイルを自動で録画して
MP4 動画に変換するツールです。
複数のリプレイを順番に一括録画（バッチ録画）できます。


【使い方】

1. 非想天則リプレイ録画.exe を起動する
   ※ 管理者権限の確認ダイアログが出たら「はい」を選んでください

2. 「th123.EXE」欄に東方非想天則の実行ファイルを指定する
   （参照ボタンから選択できます）

3. 「.rep ファイル」欄に録画したいリプレイファイルを追加する
   ・「追加」ボタンを押してファイルを選択 (複数同時選択可)
   ・リストに表示された順番に録画されます
   ・「削除」で選択中のファイルを除外、「全削除」で一覧をクリア

4. 「出力フォルダ」欄に MP4 の保存先を指定する

5. 「録画開始」ボタンを押す

6. リプレイが 1 件ずつ自動で録画されます
   ・ゲームが自動起動してリプレイが再生されます
   ・推定再生時間を過ぎると自動で録画が止まり、次のファイルへ進みます
   ・途中で止めたい場合は「録画停止」ボタンを押してください
     （停止後は残りのバッチもすべてキャンセルされます）

7. 録画が完了するとログに「保存完了」と表示され、全件終わると
   「全 N 件の録画が完了しました」と表示されます

※ ファイル名は .rep のファイル名と同じになります (例: th123_0001.mp4)


【切り抜き機能】

録画完了後に「録画ファイルを切り抜く」ボタンを押すと
直前に録画したファイルを切り抜きウィンドウで開きます。
「ファイルを指定して切り抜く」ボタンは任意の動画ファイルを開けます。

切り抜きウィンドウの操作:
・緑のシークバー   … 開始地点の指定
・赤のシークバー   … 終了地点の指定
・◀◀/◀/▶/▶▶ ボタン … 各バーを ±1秒 / ±5秒 単位で微調整
・▶ 再生          … 開始〜終了の範囲をプレビュー再生
・切り抜き実行     … 元ファイルと同じフォルダに「_clip」付きで保存

※ opencv-python と Pillow が必要です (未導入の場合はウィンドウ内に案内が出ます)


【詳細設定】

起動待ち(秒)   ゲーム起動後にキー操作を始めるまでの待機時間
               ゲームの起動が遅い場合は増やしてください（デフォルト: 5）

キー間隔(秒)   各キー操作の間隔（デフォルト: 0.3）

メニュー↓回数  タイトル画面からリプレイ鑑賞メニューへ移動する↓キーの回数
               MOD 等でメニュー構成が変わっている場合は調整してください
               （デフォルト: 6）

選択後Z回数    リプレイ選択・再生開始のZキー回数（デフォルト: 4）

録画品質(CRF)  FFmpeg の映像品質パラメータ
               数値が低いほど高品質・大容量、高いほど低品質・小容量
               0 が完全無損失、51 が最低品質（デフォルト: 20）

プリセット     FFmpeg のエンコード速度と圧縮率のバランス設定
               veryfast / faster / fast / medium / slow など
               遅いほど同じ品質でファイルサイズが小さくなるが録画後の
               変換に時間がかかります（デフォルト: veryfast）


【注意事項】

・録画中はゲームウィンドウが最前面に固定されます
・ゲームのリプレイフォルダに一時ファイルを作成しますが、録画後に自動削除されます
・出力フォルダに同名の .mp4 が存在する場合は上書きされます
・SWRSToys 等の MOD を使用している場合、メニュー構成が変わることがあります
  その場合は「メニュー↓回数」を調整してください
・バッチ録画中に「録画停止」を押すと、現在録画中のファイルで停止し
  残りのファイルはすべてキャンセルされます
